# Phase 6 – Project Testing

## Project Name
EduGenie: Google Gemini Powered Learning Assistant

## Testing Objective
To verify that all EduGenie learning features work correctly and provide expected responses.

## Functional Testing

### Test 1 – Question and Answer
Input:
What is Artificial Intelligence?

Expected Result:
EduGenie provides a clear and accurate answer.

### Test 2 – Concept Explanation
Input:
Photosynthesis

Expected Result:
EduGenie explains the concept in simple language.

### Test 3 – Quiz Generation
Input:
Python programming basics

Expected Result:
EduGenie generates 3 multiple-choice questions with 4 options each.

### Test 4 – Text Summarization
Input:
Educational text about Artificial Intelligence.

Expected Result:
EduGenie provides a concise summary containing the important points.

### Test 5 – Personalized Learning Path
Input:
Python programming

Expected Result:
EduGenie provides a learning path from beginner to advanced concepts.

## Testing Result
All major learning features are tested through the web interface and verified for expected functionality.

## Conclusion
Functional testing confirms that EduGenie performs its core educational assistance tasks through the FastAPI backend and Google Gemini API.
