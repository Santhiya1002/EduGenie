# Phase 7 – Project Documentation

## Project Name
EduGenie: Google Gemini Powered Learning Assistant

## Project Overview
EduGenie is a web-based AI learning assistant designed to help students with educational tasks using Google Gemini.

## Main Features
- Question and Answer
- Concept Explanation
- Quiz Generation
- Text Summarization
- Personalized Learning Path

## Technologies Used
- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- JavaScript
- Jinja2

## Project Structure
The project contains separate Python modules for each learning feature, a FastAPI backend, and a web-based frontend.

## API Endpoints
- `/qa` – Question and Answer
- `/explain` – Concept Explanation
- `/quiz` – Quiz Generation
- `/summarize` – Text Summarization
- `/learn/recommendations` – Personalized Learning Path

## Security
The Gemini API key is stored using an environment variable and is not included in the GitHub repository.

## Testing
The main learning features were tested through the web interface to verify their functionality.

## Conclusion
EduGenie provides students with an easy-to-use AI-powered learning assistant for understanding concepts, getting answers, creating quizzes, summarizing text, and following personalized learning paths.
