# Phase 8 – Project Demonstration

## Project Name
EduGenie: Google Gemini Powered Learning Assistant

## Demonstration Objective
To demonstrate the working of EduGenie and show how it assists students with different learning tasks.

## Demonstration Flow

### 1. Project Introduction
Introduce EduGenie and explain its purpose as an AI-powered learning assistant.

### 2. Question and Answer
Demonstrate the Q&A feature by entering:
What is Artificial Intelligence?

Show the generated answer.

### 3. Concept Explanation
Enter:
Photosynthesis

Show how EduGenie explains the concept in simple language.

### 4. Quiz Generation
Enter:
Python programming basics

Show the generated multiple-choice quiz.

### 5. Text Summarization
Enter educational text about Artificial Intelligence and demonstrate the summary feature.

### 6. Personalized Learning Path
Enter:
Python programming

Show the learning path generated from beginner to advanced concepts.

## Benefits
- Helps students understand difficult topics.
- Provides quick educational answers.
- Generates practice quizzes.
- Summarizes educational content.
- Provides a structured learning path.

## Demonstration Requirements
The project demonstration should include:
- Project name
- Project purpose
- Benefits and uses
- Execution and working process
- Final output
- Screen sharing
- Voice-over explanation

## Conclusion
The demonstration shows how EduGenie uses Google Gemini and a FastAPI-based web application to provide AI-powered educational assistance.
