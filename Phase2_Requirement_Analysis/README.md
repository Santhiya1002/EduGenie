# Phase 2 – Requirement Analysis

## Project Name
EduGenie: Google Gemini Powered Learning Assistant

## Functional Requirements
EduGenie should provide the following functions:

1. Question and Answer
   - Accept a student's question.
   - Generate a clear educational answer using Google Gemini.

2. Concept Explanation
   - Accept a topic from the student.
   - Explain the concept in simple and understandable language.

3. Quiz Generation
   - Generate 3 multiple-choice questions.
   - Provide 4 options for each question.
   - Display the correct answer.

4. Text Summarization
   - Accept educational text.
   - Generate a short and easy-to-understand summary.

5. Personalized Learning Path
   - Accept a learning topic.
   - Generate a learning path from beginner to advanced level.

## Software Requirements
- Python 3.10 or above
- FastAPI
- Google Gemini API
- Uvicorn
- Jinja2
- HTML
- CSS
- JavaScript
- Web Browser
- VS Code

## Hardware Requirements
- Computer or Laptop
- Internet Connection
- Minimum 4 GB RAM
- Keyboard and Mouse

## API Requirement
A Google Gemini API key is required to access the Gemini AI model.

## Security Requirements
- API keys must not be uploaded to GitHub.
- API keys should be stored in environment variables using a `.env` file.
- The `.env` file should be excluded using `.gitignore`.

## Phase 2 Outcome
The functional, software, hardware, API, and security requirements for EduGenie were identified.
